# Project Overview

## Objective
Create a single executive summary that gives HR and leadership teams a fast, reliable picture of the workforce. Instead of reviewing multiple spreadsheets, stakeholders can use one interactive dashboard to monitor workforce size, movement, location, and representation.

## Data source
This project uses a public HR analytics dataset sourced from Kaggle for learning and portfolio purposes. The dataset is used to demonstrate dashboard design, analytical thinking, and Power BI reporting techniques.

## Intended audience
- HR leaders monitoring workforce health and employee movement
- Business leaders seeking a high-level workforce snapshot
- Analysts who need to explore workforce trends by time period, department, location, or demographic group

## Questions this dashboard helps answer
1. What is the current workforce size, and how has it changed through hires and terminations?
2. How is the workforce split between HQ and remote employees?
3. Which locations and departments have the largest employee populations?
4. What does workforce representation look like across gender, age groups, and race?
5. How have hiring and termination patterns evolved over time?

## Metrics included
- Current headcount
- Cumulative hires and terminations
- Hires and terminations in the selected period
- HQ versus remote workforce distribution
- Location, department, and demographic breakdowns
- Hiring and termination trends by year

## Implementation highlights
- Data preparation and transformation in Power Query
- Reusable DAX measures for headcount and period-based metrics
- Interactive filtering with a year slicer
- Consistent visual hierarchy designed for executive scanability
